ስለ እኔ

እንኳን ወደ የግል መረጃ መድረኬ በሰላም መጡ። እኔ መምህር አብዱሰላም እባላለሁ፤ በአይሲቲ (ICT) ዘርፍ ለበርካታ ዓመታት በማስተማር እና በቴክኖሎጂ ድጋፍ ስራዎች ላይ ተሰማርቼ እገኛለሁ።

ዋናው ዓላማዬና ፍላጎቴ ወጣቱ ትውልድ በዲጂታል እውቀት እንዲበለጽግ እና የቴክኖሎጂ ውጤቶችን ለችግር ፈቺነት እንዲጠቀም ማገዝ ነው። ከማስተማር ጎን ለጎን የዌብ ሳይት ግንባታ፣ የኔትወርክ ዝርጋታ እና የኮምፒውተር ጥገና ስራዎችን በብቃት እሰራለሁ።

የማስተምራቸው የትምህርት አይነቶች

የተማሪዎቼን የቴክኖሎጂ እውቀት ለማሳደግ የምሰጣቸው ዋና ዋና ስልጠናዎች የሚከተሉት ናቸው፦

የዌብ ሳይት ግንባታ

ከመሰረታዊው HTML እና CSS ጀምሮ እስከ ዘመናዊ የዌብ ሳይት ዲዛይን እና አሰራር ድረስ ለጀማሪዎችም ሆነ መካከለኛ እውቀት ላላቸው ተማሪዎች ስልጠና እሰጣለሁ።

የኮምፒውተር ኔትወርክ

የአካባቢ ኔትወርክ (LAN) ዝርጋታ፣ የራውተር እና ስዊች ኮንፊገሬሽን እንዲሁም የኔትወርክ ደህንነት አጠባበቅን በተግባር የተደገፈ ትምህርት እሰጣለሁ።

የኮምፒውተር ጥገና

የሃርድዌር እና የሶፍትዌር ጥገና፣ ኦፕሬቲንግ ሲስተም መጫን (Formatting) እና የቫይረስ መከላከያ ዘዴዎችን በማስተማር ቴክኒካዊ እውቀትን አጋራለሁ።
